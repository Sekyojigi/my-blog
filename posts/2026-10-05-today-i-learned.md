오늘 클로드 코드와 함께 이 블로그를 처음부터 만들었습니다. 프레임워크 없이 **HTML, CSS, JavaScript** 세 가지만 썼는데, 덕분에 각자가 무슨 일을 하는지 또렷하게 보였습니다.

집 짓기에 비유하면 이렇습니다.

- **HTML**은 뼈대: 방이 몇 개이고 문이 어디에 있는지
- **CSS**는 인테리어: 벽지 색과 가구 배치
- **JavaScript**는 전기와 스위치: 누르면 불이 켜지는 동작

## HTML: 내용과 구조

HTML은 화면에 *무엇이* 있는지를 정합니다. 이 블로그의 `index.html`에는 머리말(`header`), 본문(`main`), 꼬리말(`footer`)이 있습니다.

```html
<header class="site-header">
  <a class="site-title" href="#/">투자 동호회</a>
</header>
<main id="app"></main>
```

`div`만 쓰지 않고 `header`, `main`, `article`처럼 뜻이 있는 태그를 쓰면 스크린 리더와 검색엔진도 내용을 더 잘 이해합니다.

## CSS: 모양과 배치

CSS는 그 내용이 *어떻게 보일지*를 정합니다. 글자 크기, 줄간격, 색, 여백이 모두 CSS의 일입니다.

가장 인상 깊었던 것은 **CSS 변수**로 다크 모드를 만드는 방법이었습니다. 색을 변수로 한 곳에 모아 두고, 다크 모드일 때 변수 값만 바꾸면 사이트 전체 색이 한 번에 바뀝니다.

```css
:root {
  --bg: #ffffff;
  --text: #1d2127;
}

:root[data-theme="dark"] {
  --bg: #121418;
  --text: #e4e6ea;
}

body {
  background: var(--bg);
  color: var(--text);
}
```

모바일 대응도 CSS가 맡습니다. 작은 화면을 기준으로 먼저 만들고, `@media (min-width: 640px)`로 넓은 화면에서만 여백과 글자를 키웠습니다.

## JavaScript: 동작

JavaScript는 화면이 *어떻게 움직일지*를 정합니다. 이 블로그에서는 다음 일을 맡습니다.

1. `posts/` 폴더의 마크다운 파일을 불러오기
2. 마크다운을 HTML로 바꾸기
3. 주소(`#/post/...`)에 따라 목록과 글 화면을 바꿔 보여주기
4. 테마 버튼을 누르면 다크 모드로 전환하고 선택을 기억하기

예를 들어 테마 전환은 버튼을 누를 때 `html` 태그의 속성 하나만 바꿉니다. 실제 색을 바꾸는 일은 위의 CSS가 합니다.

```js
button.addEventListener('click', () => {
  const next = currentTheme() === 'dark' ? 'light' : 'dark';
  document.documentElement.setAttribute('data-theme', next);
});
```

세 가지가 각자 맡은 일만 하고 서로 협력한다는 점이 재미있었습니다.

## 한눈에 정리

| 기술 | 역할 | 이 블로그에서 한 일 |
| --- | --- | --- |
| HTML | 내용과 구조 | 머리말, 본문, 꼬리말, 테마 버튼 |
| CSS | 모양과 배치 | 글꼴, 다크 모드 색, 모바일 레이아웃 |
| JavaScript | 동작 | 글 불러오기, 마크다운 변환, 화면 전환 |

## 덤으로 알게 된 것

- 브라우저는 보안 때문에 파일을 더블클릭해서 열면 다른 파일을 읽지 못합니다. 그래서 `python -m http.server 8000`으로 **로컬 서버**를 띄워서 봐야 합니다.
- 글에 들어간 내용을 그대로 HTML로 넣으면 위험할 수 있습니다. `<script>` 같은 글자가 코드로 실행되지 않도록 먼저 바꿔 주는 **이스케이프** 처리가 중요합니다.
- `CLAUDE.md`에 프로젝트 규칙을 적어 두면 클로드 코드가 그 규칙을 따라 일관되게 작업합니다.
