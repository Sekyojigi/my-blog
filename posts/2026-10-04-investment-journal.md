투자 일지는 **결과**보다 *결정을 내린 이유*를 남기는 기록입니다. 시간이 지나 다시 읽으면 내가 어떤 생각을 했는지, ~~운이었는지~~ 판단이 맞았는지 돌아볼 수 있습니다.

- [기록 예시 표](#기록-예시-표)

## 일지에 적을 것

1. 날짜와 상황
2. 내가 내린 결정
   - 무엇을 했는지
   - 왜 그렇게 판단했는지
3. 다음에 확인할 것

> 기록하지 않은 판단은 시간이 지나면 기억 속에서 그럴듯하게 바뀝니다.
> 그래서 쓰는 순간의 생각을 그대로 남기는 것이 중요합니다.

아래 숫자는 설명을 위한 예시입니다.

| 2026-10-01 | 회고 | 한 달 기록을 다시 읽고 느낀 점 정리 | - |

## 마크다운 문법 모음

### 인라인

`인라인 코드`, **굵게**, *기울임*, ~~취소선~~, [외부 링크](https://ko.wikipedia.org/wiki/투자)를 쓸 수 있습니다.

아주 긴 주소도 화면 밖으로 넘치지 않습니다: https://example.com/very/long/path/that/should/wrap/on/small/screens/without/horizontal/scroll

### 코드 블록

```js
// 수익률 계산 예시
function returnRate(buy, now) {
  return ((now - buy) / buy) * 100;
}
console.log(returnRate(10000, 12500).toFixed(1) + '%'); // 25.0%
```
